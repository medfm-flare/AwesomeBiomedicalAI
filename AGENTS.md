Never use system-wide Python; always use `uv` (if available, preferred) or standard `python3 -m venv` to create a repo-local `.venv` and use Python from there. You may freely install packages within that `.venv` to use as necessary and/or appropriate (e.g. PyMuPDF/PyPDF). Never git commit on your own unless the user has explicitly granted you permission. Always self-review your work before handing it back to the user to ensure your changes are correct and verified.
